## 1. R이란?

### 1.1 정의와 역사

R은 통계 컴퓨팅과 그래픽을 위해 설계된 프로그래밍 언어이자 무료 소프트웨어 환경이다. R은 뉴질랜드 오클랜드 대학교의 Ross Ihaka와 Robert Gentleman이 개발했으며, 1995년에 자유 소프트웨어로 공개되었다.

- R은 S 프로그래밍 언어의 구현체이다.
- 통계학자와 데이터 과학자 사이에서 데이터 분석, 통계 모델링, 시각화에 널리 사용된다.
- R은 오픈 소스이며, CRAN에 19,000개가 넘는 패키지가 등록된 방대한 패키지 생태계를 보유하고 있다.

### 1.2 GIS 통계학에 R을 사용하는 이유

R은 GIS 관련 통계 분석에 여러 가지 장점을 제공한다.

- **공간 데이터 처리:** `sf`, `sp`, `terra` 등 공간 데이터를 다루는 패키지를 제공한다.
- **통계 모델링:** 회귀분석, 시계열분석, 분류 등을 위한 내장 함수를 제공한다.
- **시각화:** `ggplot2`로 지도를 포함한 출판 수준의 그래픽을 제작할 수 있다.
- **재현성:** 스크립트 기반 분석이 재현 가능한 연구를 뒷받침한다.
- **통합성:** 셰이프파일, GeoJSON, 래스터 데이터, 웹 매핑 서비스와 연동할 수 있다.

> **핵심:** R은 전통적인 GIS 소프트웨어와 고급 통계 기법 사이의 격차를 메워 주므로 공간 데이터 분석에 적합한 도구이다.

## 2. R 및 RStudio 설치

### 2.1 R 설치

R은 CRAN(Comprehensive R Archive Network)에서 다운로드할 수 있다.

- 웹사이트: https://cran.r-project.org/
- Windows, macOS, Linux에서 사용할 수 있다.

### 2.2 RStudio IDE

RStudio는 R에서 가장 널리 사용되는 통합 개발 환경(IDE)이며, 기본 배치에서 창이 네 개의 패널로 나뉜다.

- **Console:** R 명령어를 대화식으로 실행한다.
- **Script Editor:** R 스크립트(.R 파일)를 작성하고 저장한다.
- **Environment 패널:** 메모리에 있는 변수와 데이터를 확인한다.
- **Plots/Help 패널:** 시각화 결과와 문서를 확인한다.

```text
┌──────────────────────┬────────────────────────────┐
│ Script Editor        │ Environment / History      │
│                      │                            │
├──────────────────────┼────────────────────────────┤
│ Console              │ Files / Plots /            │
│                      │ Packages / Help            │
└──────────────────────┴────────────────────────────┘
```

*그림 1. RStudio의 기본 패널 배치*

### 2.3 기본 R 콘솔 연산

```r
# 기본 산술 연산
2 + 3          # 덧셈
10 - 4         # 뺄셈
5 * 6          # 곱셈
20 / 4         # 나눗셈
20 %/% 7       # 정수 나눗셈 (몫) -> 2
20 %% 7        # 나머지 연산 -> 6
6 ^ 2          # 거듭제곱 -> 36
6 ** 2         # 거듭제곱 (대체 표기) -> 36
```

### 2.4 도움말 사용

```r
help(mean)       # mean() 함수의 도움말 페이지 열기
?mean            # help()의 단축 표기
help(data.frame) # data.frame 함수의 도움말
```

> **핵심:** `help()`로 연 도움말 페이지는 해당 함수가 어느 패키지에 속해 있는지 보여 준다. 예를 들어 `mean {base}`는 `mean()`이 `base` 패키지에 있음을 의미한다.

## 3. 통계 프로그래밍 언어로서의 R

### 3.1 변수 할당

R은 변수 할당에 `<-` 연산자(권장) 또는 `=`를 사용한다.

```r
a <- 4       # 변수 a에 4를 할당
b <- 20      # 변수 b에 20을 할당
c <- a + b   # c = 24
```

**변수 이름 규칙:**
- 문자 또는 마침표(`.`)로 시작해야 하며, 마침표로 시작하면 바로 뒤에 숫자가 올 수 없다.
- 숫자, 밑줄, 특수 문자로 시작할 수 없다.
- 대소문자를 구분한다(`exam`과 `Exam`은 다른 변수이다).
- 공백을 쓸 수 없으므로 단어를 구분할 때는 밑줄(`_`)을 사용한다.
- `if`, `TRUE`, `function` 같은 예약어는 이름으로 쓸 수 없다.

| 유효한 이름 | 유효하지 않은 이름 |
|-------------|-------------------|
| `exam`      | `1exam`           |
| `.exam`     | `_exam`           |
| `e1axm`     | `$exam`           |
| `e_xam`     | `ex a`            |

*표 1. 유효한 변수 이름과 유효하지 않은 변수 이름의 예*

### 3.2 할당 연산자 상세

```r
A <- 2       # <-를 사용한 할당
B = 10       # =를 사용한 할당 (작동하지만 <-가 권장됨)
C = D <- 5   # C와 D 모두 5가 됨

# 중요한 차이: <-는 =보다 우선순위가 높다
# 함수 인수 내에서는 명명된 매개변수에 =를 사용해야 한다
sum(x <- 1)  # x가 전역 환경에 1로 할당됨
sum(y = 1)   # y는 명명된 인수이며, 전역적으로 할당되지 않음
```

> **핵심:** R에서는 할당에 `=`보다 `<-`를 권장한다. `<-`는 연산자 우선순위가 더 높고, `=`는 함수 인수를 지정하는 데에도 쓰여 할당과 혼동될 수 있기 때문이다.

### 3.3 R의 데이터 유형

R에는 여러 가지 기본 데이터 유형이 있다.

| 유형 | 설명 | 예시 |
|------|------|------|
| `numeric` | 실수 | `3.14`, `42` |
| `integer` | 정수 | `1L`, `100L` |
| `character` | 문자열 | `"Hello"`, `'World'` |
| `logical` | 논리값 | `TRUE`, `FALSE` |
| `factor` | 범주형 데이터 | `factor(c("A", "B"))` |
| `complex` | 복소수 | `3+2i` |

*표 2. R의 기본 데이터 유형*

```r
# 유형 확인
class(42)           # "numeric"
class(TRUE)         # "logical"
class("Hello")      # "character"
class(factor("A"))  # "factor"

typeof(1:10)        # "integer"
```

`factor`는 나머지 다섯 유형과 달리 정수 벡터에 수준(levels) 속성을 붙인 클래스이다. 따라서 `class(factor("A"))`는 `"factor"`이지만 `typeof(factor("A"))`는 `"integer"`이다. 팩터는 2장에서 자세히 다룬다.

## 4. GIS와 통계학

### 4.1 GIS란?

지리정보시스템(GIS, Geographic Information System)은 공간 및 지리 데이터를 수집, 관리, 분석하기 위한 프레임워크이다. GIS는 다음 세 요소를 통합한다.

- **공간 데이터:** 좌표, 경계 같은 위치 기반 정보이다.
- **속성 데이터:** 공간 객체와 연관된 특성이다.
- **통계 기법:** 지리 데이터에 적용되는 분석 방법이다.

### 4.2 GIS에서의 통계 기법

지리 데이터에는 다음과 같은 통계 기법이 흔히 쓰인다.

1. **기술 통계:** 공간 데이터의 분포를 요약한다.
2. **데이터 시각화:** `ggplot2`를 활용해 지도와 차트를 제작한다(5~6장).
3. **회귀분석:** 지리 변수 간 관계를 모델링한다(7장).
4. **시계열분석:** 공간 데이터의 시간적 패턴을 분석한다(8장).
5. **로지스틱 회귀:** 결과가 두 범주 중 하나인 공간 데이터를 분류한다(9장).

### 4.3 GIS 통계를 위한 주요 R 패키지

| 패키지 | 용도 |
|--------|------|
| `ggplot2` | 데이터 시각화 및 지도 제작 |
| `dplyr` | 데이터 조작 및 변환 |
| `sf` | 공간 데이터를 위한 Simple Features |
| `mapview` | 대화형 지도 시각화 |
| `choroplethr` | 단계구분도(Choropleth map) 생성 |
| `tidyverse` | 데이터 과학 패키지 모음 |

*표 3. GIS 통계에 쓰이는 주요 R 패키지*

## 점검 문제

1. **산술 연산자:** `17 %/% 5`, `17 %% 5`, `2 ** 5`의 결과를 쓰라.

   <details>
   <summary>정답</summary>

   `%/%`는 정수 나눗셈의 몫을 구하므로 17 = 5 × 3 + 2에서 `17 %/% 5`는 3이다. `%%`는 나머지를 구하므로 `17 %% 5`는 2이다. `**`는 `^`와 같은 거듭제곱 연산자이므로 `2 ** 5`는 $2^5 = 32$이다.

   </details>

2. **변수 이름:** `my.data`, `2nd_value`, `_temp`, `value_2`, `.5x`, `if` 중 유효한 변수 이름을 고르고, 나머지가 유효하지 않은 이유를 쓰라.

   <details>
   <summary>정답</summary>

   유효한 이름은 `my.data`와 `value_2`이다. `2nd_value`는 숫자로, `_temp`는 밑줄로 시작한다. `.5x`는 마침표로 시작하지만 바로 뒤에 숫자가 오므로 R이 앞부분을 수 0.5로 읽는다. `if`는 예약어이다.

   </details>

3. **할당과 명명된 인수:** 새 R 세션에서 `sum(x <- 3)`과 `sum(y = 3)`을 차례로 실행한 뒤 `exists("x")`와 `exists("y")`의 결과를 쓰고 이유를 설명하라.

   <details>
   <summary>정답</summary>

   `exists("x")`는 `TRUE`, `exists("y")`는 `FALSE`이다. 인수 자리의 `x <- 3`은 할당 식으로 평가되어 전역 환경에 `x`를 만든 뒤 그 값 3을 `sum()`에 넘긴다. 반면 `y = 3`은 `y`라는 이름의 인수에 3을 넘기는 명명된 인수 지정이므로 변수 `y`가 만들어지지 않는다.

   </details>

4. **데이터 유형:** `class(5)`, `class(5L)`, `class(TRUE)`, `class("5")`, `class(factor("5"))`의 결과를 쓰라.

   <details>
   <summary>정답</summary>

   순서대로 `"numeric"`, `"integer"`, `"logical"`, `"character"`, `"factor"`이다. 숫자 리터럴 5는 기본적으로 실수(numeric)이고, 접미사 `L`을 붙여야 정수(integer)가 된다. 따옴표로 감싼 `"5"`는 숫자가 아니라 문자열이다.

   </details>

5. **GIS의 구성 요소:** GIS가 통합하는 세 가지 요소를 쓰고, 시군구별 인구 지도를 예로 들어 각 요소가 무엇에 해당하는지 설명하라.

   <details>
   <summary>정답</summary>

   GIS는 공간 데이터, 속성 데이터, 통계 기법을 통합한다. 시군구별 인구 지도에서 각 시군구의 경계 좌표는 공간 데이터이고, 각 시군구의 인구 수는 그 공간 객체에 연결된 속성 데이터이다. 인구의 분포를 요약하거나 인구와 다른 변수의 관계를 회귀분석으로 모델링하는 것이 통계 기법에 해당한다.

   </details>
