## Problem. Drawing the Figures of Chapters 5-8 in R

Use the following book and website.

- **Book:** R. Kabacoff, *Modern Data Visualization with R*, CRC Press
- **Website:** https://rkabacoff.github.io/datavis/

From each of the four chapters below, choose at least 5 figures you like. You therefore choose at least 20 figures, type the R code of each figure into the R source pane or copy and paste it, run it, and check the figure that appears in the plot pane.

| Chapter | Title |
|:-----|:-----|
| Chapter 5 | Bivariate Graphs |
| Chapter 6 | Multivariate Graphs |
| Chapter 7 | Maps |
| Chapter 8 | Time-dependent graphs |

*Table 1. The four chapters to choose figures from*

Build the report in the following order.

1. **step 1:** Capture the code in the console pane and the figure in the plot pane. That is, capture the R console pane so that its colors are visible, and capture the figure in the plot pane.
2. **step 2:** Edit the captures appropriately in hwp or Word. Edit them carefully so that the table of contents can be told apart; otherwise points may be deducted.
3. **step 3:** Convert the document to a PDF file and submit it on the LMS.
4. **step 4:** Name the file `Global_StudentID_Name.pdf`.
